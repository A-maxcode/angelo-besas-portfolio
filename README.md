Development

The project uses Bun scripts.

Install dependencies

bun install

Start development server

bun run dev

Production build

bun run build

Development-mode build

bun run build:dev

Preview production build

bun run preview

Run lint

bun run lint

Run tests

bun run test

Run tests in watch mode

bun run test:watch

Format source files

bun run format
